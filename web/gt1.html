Mazda MX-5 RFGran Turismo · PlayStation

La version Europe multi-langues du jeu (PAL, SCES-00984), jouée dans DuckStation ou un autre émulateur PlayStation. La MX-5 RF prend la place des Eunos Roadster, et tu obtiens une nouvelle image disque .bin + .cue, fabriquée à partir de ta copie du jeu (.chd, .cue/.bin ou .bin) et du modèle : aucun fichier du jeu n'est fourni ici.

▶ Paquet Windows (conseillé)

Le plus simple (Windows), environ une minute : télécharge le paquet, mets ton image du jeu et mazda_mx5_rf.kn5 dans son dossier, puis double-clique sur FABRIQUER.bat. Il pose les questions (Roadster, toit, prix) en français ou en anglais. Sans Python sur le PC, il télécharge une copie portable officielle (python.org) dans son dossier, rien n'est installé dans Windows.

Télécharger MX5-RF_GranTurismo1.zip

Sans Windows (Mac, Linux…) : la page ci-dessous fait la même chose dans ton navigateur, rien n'est envoyé sur internet. C'est bien plus lent (compte une vingtaine de minutes) : garde l'onglet ouvert.

01 Tes fichiers

02 La MX-5

Chaque Roadster devient

Pour chaque Roadster : la MX-5 RF capotée, décapotée, ou la Roadster d'origine. Sa version course (après la préparation course, Racing Modification) prend le même toit. Toutes les Roadster partagent une même page INFO (l'historique) : elle devient celle de la MX-5 RF dès qu'une seule est remplacée.

Astuce : mets 100 pour pouvoir acheter la MX-5 dès le début d'une nouvelle partie. 29 900 Cr, c'est à peu près son vrai prix à l'échelle du jeu.

Cheat GranTurismo1-OverlayCheat (maintenir Select : figer le chrono des permis, changer les crédits) : le paquet Windows te le propose ; avec la page, ajoute-le ensuite à ton disque avec son patch .ppf (téléchargement).

03 Fabriquer

quelques minutes : c'est ton navigateur qui fait tout le travail. L'image disque (~690 Mo) est écrite au fur et à mesure : dans Chrome et Edge tu choisis d'abord où l'enregistrer ; ailleurs elle est gardée dans le stockage du site jusqu'au téléchargement. Laisse l'onglet ouvert pendant ce temps.

Télécharger le .bin

04 Jouer

  1. Mettre le .bin et le .cue dans le même dossier, avec les noms qu'ils ont reçus (le .cue donne le nom du .bin : si ton navigateur l'a renommé, remets le même nom).
  2. Dans DuckStation (ou un autre émulateur), ouvrir le .cue.
  3. La MX-5 RF est chez le concessionnaire Mazda (à la place des Eunos Roadster) et dans les voitures d'occasion, avec son nom, ses 184 ch, ses huit peintures (Deep Crystal Blue, Soul Red Crystal, Machine Grey…) et sa page INFO.
  4. Ton .chd n'est pas modifié : pour revenir en arrière, il suffit de le relancer.
